# Releases: download, compile and run

Document timestamp: 2026-11-15T01:28:16Z · applies to wa2dc-unified 2.7.0 (tag `unified-v2.7.0`)

Replace `<owner>` below with the GitHub account that hosts your copy of the repository.

## 1. What a release contains

Each `unified-v*` tag produces a GitHub Release (`https://github.com/<owner>/wa2dc-unified/releases`) with:

| Asset | Contents |
| --- | --- |
| `wa2dc-unified-<version>-source.tar.gz` / `.zip` | Complete source of all three bridges, installers and docs |
| `hummus-linux-x64`, `hummus-linux-arm64`, `hummus-windows-x64.exe` | Prebuilt Hummus (Go) binaries |
| `install-linux_v1.0.0_2026-11-15T012816Z.sh`, `install-windows_v1.0.0_2026-11-15T012816Z.ps1` | The installers, also inside the source archive |
| `SHA256SUMS.txt` | SHA-256 checksums of every asset |

The main bridge and OSdc-wa are Node.js programs: they are installed from source with `npm ci`, there is nothing to compile by hand. (Upstream's signed single-file binaries of the main bridge are still published by [arespawn/WhatsAppToDiscord](https://github.com/arespawn/WhatsAppToDiscord/releases); they do not contain the features merged here.)

## 2. Download

### Linux

```bash
VERSION=2.7.0
BASE=https://github.com/<owner>/wa2dc-unified/releases/download/unified-v$VERSION
curl -fLO "$BASE/wa2dc-unified-$VERSION-source.tar.gz"
curl -fLO "$BASE/SHA256SUMS.txt"
sha256sum --check --ignore-missing SHA256SUMS.txt
sudo mkdir -p /opt/wa2dc-unified
sudo tar -xzf "wa2dc-unified-$VERSION-source.tar.gz" --strip-components=1 -C /opt/wa2dc-unified
cd /opt/wa2dc-unified
```

`sha256sum` must print `OK` for the archive. Stop if it does not.

### Windows (PowerShell)

```powershell
$Version = '2.7.0'
$Base = "https://github.com/<owner>/wa2dc-unified/releases/download/unified-v$Version"
Invoke-WebRequest "$Base/wa2dc-unified-$Version-source.zip" -OutFile "$env:TEMP\wa2dc.zip"
Invoke-WebRequest "$Base/SHA256SUMS.txt" -OutFile "$env:TEMP\SHA256SUMS.txt"
(Get-FileHash "$env:TEMP\wa2dc.zip" -Algorithm SHA256).Hash.ToLower()
Select-String "source.zip" "$env:TEMP\SHA256SUMS.txt"
Expand-Archive "$env:TEMP\wa2dc.zip" -DestinationPath C:\
Rename-Item "C:\wa2dc-unified-$Version" C:\wa2dc-unified
Set-Location C:\wa2dc-unified
```

The hash printed by `Get-FileHash` must equal the one shown by `Select-String`.

### From git instead of a release archive

```bash
git clone --branch unified-v2.7.0 https://github.com/<owner>/wa2dc-unified.git
cd wa2dc-unified
```

## 3. Compile / install

### Automatic

Linux:

```bash
sudo bash deploy/linux/install-linux_v1.0.0_2026-11-15T012816Z.sh --bridge main
```

Windows (elevated PowerShell):

```powershell
Set-ExecutionPolicy -Scope Process Bypass -Force
.\deploy\windows\install-windows_v1.0.0_2026-11-15T012816Z.ps1 -Bridge main
```

Use `--bridge osdc-wa` / `-Bridge osdc-wa` or `hummus` for the other bridges. Add `--dry-run` (Linux) or `-WhatIf` (Windows) to see what would happen without changing anything. The installers install the prerequisites, build the bridge, create `.env` from the template and register a service (systemd unit `wa2dc-unified-<bridge>.service`, or a disabled scheduled task `wa2dc-unified-<bridge>` on Windows).

### Manual

| Bridge | Prerequisites | Build |
| --- | --- | --- |
| main | Node.js 24.22.1–24.x or 26.12.1+, git, a C/C++ toolchain, cairo/pango/jpeg/gif/rsvg development headers (Linux), ffmpeg | `npm ci --omit=dev` |
| osdc-wa | Node.js 22+, git | `cd bridges/osdc-wa && npm ci --omit=dev` |
| hummus | Go 1.21+ (fetches the pinned toolchain), gcc | `cd bridges/hummus && CGO_ENABLED=1 go build -trimpath -o hummus .` |

Debian/Ubuntu prerequisites for the main bridge:

```bash
sudo apt-get update
sudo apt-get install -y ca-certificates curl git ffmpeg build-essential pkg-config python3 libcairo2-dev libpango1.0-dev libjpeg-dev libgif-dev librsvg2-dev
curl -fsSL https://deb.nodesource.com/setup_24.x -o nodesource_setup.sh
sudo bash nodesource_setup.sh
sudo apt-get install -y nodejs
npm ci --omit=dev
```

Optional single-file bundle of the main bridge (what upstream's CI smoke-tests):

```bash
npm ci
npm run bundle
WA2DC_SMOKE_TEST=1 node out.js
```

## 5. Run

The first start must be interactive so WhatsApp can be linked.

Main bridge:

```bash
npm start
```

It prints an invite URL for the bot, creates a `#control-room` channel and posts the WhatsApp QR code there. Scan it from WhatsApp → Linked devices.

OSdc-wa:

```bash
cd bridges/osdc-wa && npm start
```

Hummus:

```bash
cd bridges/hummus && ./hummus
```

Both print the QR code in the terminal. After linking, stop with Ctrl+C and hand over to the service.

Linux:

```bash
sudo systemctl start wa2dc-unified-main.service
```

```bash
journalctl -fu wa2dc-unified-main.service
```

Windows:

```powershell
Enable-ScheduledTask wa2dc-unified-main; Start-ScheduledTask wa2dc-unified-main
```

## 6. Upgrade

```bash
sudo systemctl stop wa2dc-unified-main.service
sudo cp -a /opt/wa2dc-unified/storage /opt/wa2dc-unified-storage-backup-$(date +%F)
```

Extract the new archive over the directory (or `git fetch --tags && git checkout unified-v<new>`), run `npm ci --omit=dev` again, then start the service. `storage/` holds the WhatsApp session and all mappings — back it up and never share it.

Update notices inside the main bridge refer to upstream arespawn releases by default. Set `WA2DC_UPDATE_REPO=<owner>/wa2dc-unified` in `.env` to follow your own releases, or `WA2DC_SKIP_UPDATE=1` to turn them off.

## 7. Publishing a release (maintainers)

First publication of the repository:

```bash
gh repo create wa2dc-unified --public --source=. --remote=origin --push
```

Every release:

```bash
npm version 2.7.1 --no-git-tag-version
```

Write `docs/unified/release-notes/unified-v2.7.1.md`, commit, then:

```bash
git tag -a unified-v2.7.1 -m "wa2dc-unified 2.7.1"
git push origin main unified-v2.7.1
```

The **Unified release** workflow checks that the tag matches `package.json`, runs lint and all test suites, builds Hummus for Linux x64/arm64 and Windows x64, creates the source archives and `SHA256SUMS.txt`, and publishes the GitHub Release with the notes file. Building the same assets locally:

```bash
mkdir -p dist
git archive --format=tar.gz --prefix=wa2dc-unified-2.7.0/ -o dist/wa2dc-unified-2.7.0-source.tar.gz unified-v2.7.0
git archive --format=zip --prefix=wa2dc-unified-2.7.0/ -o dist/wa2dc-unified-2.7.0-source.zip unified-v2.7.0
(cd bridges/hummus && CGO_ENABLED=1 go build -trimpath -ldflags "-s -w" -o ../../dist/hummus-linux-x64 .)
(cd dist && sha256sum * > SHA256SUMS.txt)
```
